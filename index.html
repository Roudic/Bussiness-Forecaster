What CSV works?

Any export with a time column and a sales column, plus a date column so the tool can sort days by weekday. Upload one big file or a stack of daily files at once. Each upload adds to what's already loaded, and a re-uploaded day replaces the old copy. Four or more of the same weekday gives the best counts.
